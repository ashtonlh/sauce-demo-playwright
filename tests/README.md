# SauceDemo Playwright Automation Framework

This project is an automated QA testing framework built using Playwright and TypeScript.

## Technologies Used
- Playwright
- TypeScript
- Page Object Model (POM)
- GitHub Actions
- Chromium Browser Testing

## Automated Test Coverage
- Valid Login Test
- Invalid Login Test
- Add To Cart Test
- Multiple Items Cart Test
- Checkout Flow Test

## Framework Structure
- pages/
- tests/
- utils/

## Features
- Reusable page methods
- Reusable test data
- Modular test structure
- End-to-end UI testing

## How To Run Tests

Run all tests:
```bash
npx playwright test --project=chromium
